# Privacy Policy - Gyroscopic Lake Live Wallpaper

Last updated: January 2024

## Data We Collect

To improve app performance and user experience, we collect:

- **Device Information**: Device model, manufacturer, Android version, hardware specifications
- **Network Information**: Carrier name, network type, country code
- **Analytics Identifiers**: Android ID and device identifiers for usage analytics

## How We Use This Data

- Performance optimization across device types
- Crash and error monitoring
- Feature usage analytics
- A/B testing for UI improvements

## Data Sharing

We do not sell your data. Analytics are processed by our internal backend (analytics-collector.nullevent.dev).

## Your Rights

Contact privacy@nullevent.dev for data deletion requests.
